# Tytuły i struktury artykułów

## Wzory tytułów

Cel: 50-60 znaków, najważniejsza obietnica w pierwszych ~50 znakach (ucinanie na telefonie). Dobieraj wzór do intencji z SERP.

| Intencja | Wzór | Przykład |
|---|---|---|
| Poradnik | Jak [osiągnąć cel]? [Konkret/zakres] | Jak być widocznym w ChatGPT? Poradnik krok po kroku |
| Poradnik z przeszkodą | Jak [cel] bez [problemu] | Jak trafić do AI Overviews bez nowych treści |
| Definicja | Czym jest [pojęcie]? [Korzyść] | Czym jest GEO? Różnice względem SEO w praktyce |
| Lista | [N] [sposobów/zasad] na [cel] | 10 zasad pisania treści, które cytuje AI |
| Diagnoza | Dlaczego [problem]? [N] przyczyn | Dlaczego ChatGPT nie cytuje strony? 8 przyczyn |
| Decyzja | Czy warto [działanie]? [Krótka odpowiedź] | Czy warto dodać llms.txt? Dane i opinie Google |
| Porównanie | [A] a [B]: [kryterium] | SEO a GEO: co zostaje, co dochodzi |
| Checklista | [Temat]: checklista [N] punktów | Treść pod AI Overviews: checklista 15 punktów |
| Dane | [Temat]: [wynik] na [próbie] | AI Overviews a pozycja w TOP 10: dane z 418 SERP-ów |
| Proces | [Działanie] krok po kroku | Odświeżanie starego artykułu pod AI krok po kroku |

**Modyfikatory**, gdy coś realnie wnoszą: rok (temat szybko się starzeje), „dane”, „przykłady”, „checklista”, grupa odbiorców („dla sklepów”, „dla agencji”).

**Unikaj**: wielkich liter, wykrzykników, superlatyw bez pokrycia („najlepszy”, „jedyny”), obietnic, których tekst nie spełnia, potocznych pytań („Po co to?”).

**Kontrola tytułu**: fraza naturalnie, format zgodny z SERP, konkretna obietnica, długość mieści się, tytuł różni się od tytułów z TOP 10.

## Struktury według formatu

Każdy format zaczyna się tak samo: bezpośrednia odpowiedź na pytanie z tytułu (1-3 zdania) → lista punktów z najważniejszymi informacjami → krótki wstęp. Kolumna „Sekcje” poniżej opisuje, co idzie dalej. Wspólne są też: sekcje zaczynające się od odpowiedzi, FAQ, zakończenie z jednym krokiem, źródła na końcu.

| Format | Kiedy | Sekcje |
|---|---|---|
| Poradnik | „jak…”, intencja informacyjna z działaniem | Wstęp z odpowiedzią → TL;DR → wymagania (czas, narzędzia) → kroki numerowane z przykładami → najczęstsze błędy → checklista → FAQ → zakończenie |
| Definicja / pillar | „czym jest…”, „co to…” | Definicja 40-60 słów → dlaczego to ważne → zasada działania → przykłady → porównanie z pokrewnym pojęciem → jak zacząć → FAQ → zasoby |
| Diagnoza | „dlaczego nie…”, „nie działa” | Szybka odpowiedź (najczęstsza przyczyna) → przyczyny jako H2, każda: objaw → jak sprawdzić → jak naprawić → tabela diagnostyczna → FAQ → zakończenie |
| Lista zasad | „N sposobów”, „zasady” | Tabela podsumowująca → kryteria → zasady jako H2 z przykładem „przed i po” → najczęstsze błędy → FAQ |
| Porównanie | „A a B”, „A vs B” | Krótki werdykt → tabela porównawcza → opis A i B → kiedy wybrać które → FAQ → werdykt |
| Raport z danymi | własne dane CitationOne | Główny wniosek → metodologia i próba → wyniki (wykres/tabela) → interpretacja i ograniczenia → co z tego wynika w praktyce → FAQ |

## Bloki w treści

| Blok | Wzorzec |
|---|---|
| Definicja | 40-60 słów, odpowiedź wprost, źródło z datą przy faktach |
| Tabela podsumowująca | Tylko pola potrzebne do decyzji |
| Wniosek z danymi | „Kluczowa liczba: [wartość] - [źródło, data]” |
| Przed i po | Dwa krótkie fragmenty tekstu obok siebie + jedno zdanie, co się zmieniło i dlaczego |
| CTA kontekstowe | Jedno zdanie łączące poprzedni dowód z audytem + link |
